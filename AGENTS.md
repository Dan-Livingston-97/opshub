
# OpsHub — AI Development Instructions

## Project Overview
OpsHub is a learning-focused business operations
intelligence platform built with Python, SQL,
Streamlit, and AI-assisted development tools.

The application simulates the operations of a
fictional wholesale distribution company.

## Development Guidelines
- Keep code simple and beginner-friendly.
- Explain important technical concepts.
- Make small, incremental changes.
- Avoid unnecessary complexity.
- Use synthetic business data only.
- Never store passwords or API keys in code.
- Document new features and dependencies.

## AI Collaboration Rules
- Explain proposed changes before implementing them.
- Help the project owner understand the code.
- Provide clear testing instructions.
- Identify potential errors and limitations.
- Do not make major architectural changes
  without approval.

## Learning Objectives
- Git and GitHub version control
- Python programming
- SQL and database management
- Data analytics and visualization
- AI-assisted development
- Business process automation
- Technical documentation
